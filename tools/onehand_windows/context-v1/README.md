## Explicit production blocker

Independent review rejected `windows-process-adapter-v1` for three reproduced defects: premature EOF could be reported completed; a writer `CloseHandle` failure could escape cleanup; and a pending OVERLAPPED wait failure lacked cancel/drain. This package's production gate unconditionally rejects that transport version before taking the owner lock or assembling. Its exact pins are retained only for read-only integrity inspection. No different helper can be silently substituted. A reviewed v2 requires a separate narrow source revision, new explicit pins and updated integration tests. The current package is not a production-admitted dependency or a Windows-production-ready route.
